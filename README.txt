ШКОЛА ДРУЖБЫ — сайт для размещения на Netlify

1. Загрузите папку сайта в Netlify (Deploy manually / drag and drop).
2. В Netlify включите Forms / Form detection, выполните повторный деплой при необходимости.
3. В настройках Forms настройте уведомления на почту.
4. Отправьте тестовую заявку и убедитесь, что она видна в Forms.
5. Перед публичным запуском утвердите политику персональных данных и проверьте требования законодательства РФ, в том числе локализацию данных. Netlify может не подходить для хранения данных граждан РФ без дополнительной правовой/технической проверки.
6. Видео пока не добавлены — необходимы файлы или ссылки.

Локально форма только показывает сообщение, заявки не отправляет.
